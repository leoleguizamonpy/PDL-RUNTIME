# PDL Runtime

Public distribution surface for the consumable PDL runtime.

This repository contains only runtime assets required by applications that use PDL: reusable visual primitives, CSS, product-neutral interaction utilities, types, and the public product UI manifest schema.

The private PDL source repository remains the source of truth. Governance, foundation, roadmap, development methodology, internal design-system documentation, tests, playgrounds, and internal tooling are intentionally not distributed here.
